# Development Workflow — Loop Plan

**Date:** 2026-08-25

---

## `/loop` Specification

### Entry
```
/loop [plan-file] [--from=TASK_ID] [--dry-run]
```

### Allowed (Safe — Repeatable Without Approval)

| Category | Examples |
|----------|----------|
| Git checks | `git status`, `git log`, `git diff`, `git branch` |
| Docker read-only | `docker ps`, `docker inspect`, `docker volume inspect` |
| Volume/mount verification | Read-only path checks |
| Test execution | `npx vitest run`, `npx playwright test` |
| Static analysis | `tsc --noEmit`, `eslint` |
| Secret scans | Pattern grep (NOT decryption) |
| Documentation | Create/edit specs, plans, TODOs, diagrams |
| Source code | Write/edit in worktrees |
| Subagent dispatch | Implementer, reviewer, debug agents |
| Mermaid validation | Syntax check |
| Review updates | Record findings, dispositions |

### Forbidden (Require Approval)

| Category | Examples |
|----------|----------|
| Commit/push | `git commit`, `git push`, `gh pr create` |
| Production migration | `ALTER TABLE`, schema changes |
| Service restart | `docker compose restart`, `docker compose up -d` |
| Production .env | Any env file modification |
| Provider activation | `NFT_PROVIDER=enhanced` |
| Auto-mint | `NFT_AUTO_MINT_ENABLED=true` |
| Blockchain | Mint, sign, submit, invoke |
| Restore | Database restore over production |
| Credentials | Decryption, printing |
| Scheduling | `crontab` modification |

### Stop Conditions

```
STOP_ON_WRONG_WORKFLOW          — target mismatch
STOP_ON_LOOP_FAILURE            — loop mechanism error
STOP_ON_RESTORE_FAILURE         — restore rehearsal fails
STOP_ON_PRODUCTION_CHANGE       — production state modification
STOP_ON_SECRET_LEAK             — credential in output
STOP_ON_BLOCKCHAIN_ACTIVITY     — any chain operation
STOP_ON_SERVICE_RESTART         — container/service restart
STOP_ON_TEST_FAILURE            — tests fail after debug
STOP_ON_UNAUTHORIZED_WRITE      — write to unauthorized path
STOP_BEFORE_PRODUCTION_MIGRATION — migration gate
STOP_BEFORE_PROVIDER_ACTIVATION  — provider gate
STOP_ON_CONTRACT_INVOCATION     — contract call
STOP_ON_MINT                    — NFT mint attempt
```

### Loop Cycle

```
1. Read TODO list
2. Find next NOT STARTED or IN PROGRESS task
3. Check preconditions
4. Check classification (read-only vs mutating)
5. If mutating + approval required → STOP
6. TDD: Write failing test → Implement → Verify GREEN
7. Review: Dispatch task reviewer
8. If Critical findings → Fix → Re-review
9. Mark VERIFIED
10. Update TODO
11. GOTO 2
```

### Resumption

On `/loop --from=TODO-007`:
1. Read TODO
2. Skip all tasks before TODO-007
3. Skip COMPLETE/VERIFIED tasks
4. Re-evaluate BLOCKED tasks
5. Continue from TODO-007

---

## Safety Guarantees

1. **No runaway:** Every stop condition halts the loop
2. **No production changes:** All production-affecting actions require gates
3. **No secret leaks:** Output is scanned for credential patterns
4. **No unbounded loops:** Max 2 debug attempts, max 2 review cycles per task
5. **Human checkpoint:** Final verification requires human review
6. **Audit trail:** TODO document records all state transitions
